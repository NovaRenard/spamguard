# SpamGuard — сценарий видео (Remotion)

**Формат:** вертикальное 1080×1920 (Reels / Shorts / Telegram-сторис), 30 fps, ~48 секунд (1440 кадров).
**Тон:** спокойный, уверенный, без запугивания. Тема ставок и лудомании серьёзная: казино на экране показываем как *угрозу*, а не как соблазн (никаких «выигрышей» и красивых слотов).
**Стиль:** тёмный интерфейс в духе Telegram, акцент синий, опасность красная, «ок» зелёная. Чат — макет, не скриншот реальных людей.
**Текст:** русский, крупные субтитры на каждой сцене (смотрят без звука).

## Технические заметки по Remotion
- Композиция `SpamGuardPromo`: `width=1080 height=1920 fps=30 durationInFrames=1440`.
- Каждая сцена — отдельный компонент в `<Sequence from durationInFrames>`; переходы через `@remotion/transitions` (`slide`, `fade`).
- Общие компоненты: `PhoneFrame`, `ChatBubble`, `Counter`, `RiskBar`, `Chip`, `NotificationCard`, `Subtitle`.
- Данные сцен — в одном JSON (тексты сообщений, проценты), чтобы менять без правки кода.
- Шрифт: Inter / Manrope (кириллица). Анимации на `spring` и `interpolate`, без `setTimeout`.
- Музыка: спокойный техно-эмбиент ~100 BPM, звуки: «пуш» на входящих, мягкий «щелчок щита» на шаге 3. Озвучка опциональна (субтитры самодостаточны).

## Честные ограничения (чтобы не вводить в заблуждение)
- Не обещаем «100% защиту» и не называем точность в процентах: модель обучена в основном на синтетических данных и ещё не проверена на реальном потоке.
- Не показываем настоящие токены, ID, QR-коды и реальные переписки — только макеты.
- Если опубликуем имя бота в кадре, нужно решить, что бот доступен только по списку разрешённых ID (сейчас так и есть).

## Вопросы, прежде чем делать видео
1. Формат: вертикальное 9:16 (как выше) или горизонтальное 16:9 для YouTube?
2. Длительность: 48 с подходит или короче (~30 с) для Reels?
3. Озвучка голосом или только субтитры и музыка?
4. Показывать ли имя бота в финале? Сейчас доступ только по списку ID.
5. Есть ли логотип/цвета бренда, или рисуем щит с нуля?
