# SpamGuard

Telegram-бот, который защищает ваш аккаунт от спама, мошенников и азартных игр (казино, ставки).
Бот входит в ваш аккаунт по QR (Telethon), проверяет сообщения **новых** собеседников и группы/каналы,
предупреждает вас и (по вашей команде) блокирует спамеров и выходит из гемблинг-групп.

Языки: русский, казахский и их смесь (в том числе транслит).

## Цель

Снизить азартную зависимость (лудоманию) на двух уровнях: **профилактика** для тех, кто ещё не сталкивался (реклама казино и ставок
просто не доходит), и **поддержка** для тех, кто уже сталкивался (меньше сообщений на глазах, меньше желания играть).
Поэтому: азартная реклама блокируется в первую очередь, её текст в уведомлениях **скрыт** (кнопка «👁 Показать текст»),
из гемблинг-групп можно выходить автоматически, а команда `/strict` включает максимальную защиту одним нажатием.
Сервис открыт всем: одобрение администратора не нужно.

## Как это работает

1. **Новый собеседник?** Не в контактах и вы ему не писали → проверяем. Если вы ответили, он «доверенный».
2. **Текст:** TF-IDF (символьные n-граммы + слова) + логистическая регрессия + правила (сильные/слабые слова).
   Это не большая нейросеть, а маленькая обучаемая модель.
3. **Профиль:** метка scam/fake от Telegram, имя/@username, «О себе», нет фото/общих чатов, серия сообщений.
4. **Итог:** `1 − (1 − текст) × (1 − профиль)`. `<50%` ничего, `50–85%` предупреждение, `≥85%` блок (если включён `/live`).
5. **Группы и каналы:** название + описание + последние сообщения (`groupcheck.py`). Автовыход только по отдельной команде.

## Запуск

```bash
pip install -r requirements.txt
cp .env.example .env        # заполните BOT_TOKEN, API_ID, API_HASH, SESSION_KEY, ALLOWED_IDS
python make_dataset.py      # синтетические данные
python train.py             # обучение + оценка на ручных примерах
python service.py
```

- `BOT_TOKEN` — от @BotFather; `API_ID`/`API_HASH` — my.telegram.org → API development tools.
- `SESSION_KEY` — `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`.
- `ADMIN_IDS` — Telegram ID администраторов: видят в панели всех пользователей, могут закрыть доступ (`/revoke`) и вернуть (`/allow`).
- `OPEN_ACCESS=1` (по умолчанию) — пользоваться может каждый, без одобрения. `OPEN_ACCESS=0` вернёт режим заявок с кнопками «Одобрить / Отклонить».
- `ALLOWED_IDS` — постоянные ID с доступом всегда (необязательно).
- `FEEDBACK_MIN_USERS=2` — сколько разных пользователей должны отметить текст «не спам», чтобы он попал в общую модель (отметка админа действует сразу).

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | QR для подключения аккаунта (сканировать на другом устройстве) |
| `/status`, `/stats` | состояние и статистика (тексты сообщений не хранятся) |
| `/strict` | защитный режим для тех, кто уже сталкивался с азартными играми: блокировка + автовыход из гемблинг-групп |
| `/live` / `/dry` | включить блокировку / только уведомления (по умолчанию `/dry`) |
| `/groupleave` | вкл/выкл автовыход из гемблинг-групп (по умолчанию выключен) |
| `/scan` | проверить все ваши группы и каналы |
| `/testmode` | тест между своими аккаунтами: бот отвечает «я бы заблокировал…», ничего не блокируя |
| `/whatsapp`, `/wastatus`, `/wastop` | подключить WhatsApp (QR в этом же боте), статус, отключить и удалить данные |
| `/walive` / `/wadry` | WhatsApp: включить блокировку и автовыход из групп / только уведомления (по умолчанию `/wadry`) |
| `/report` | личная ссылка на отчёт с графиками (сайт на Vercel, он же Mini App), см. [web/README.md](web/README.md) |
| `/stop` | выйти из аккаунта (сессия завершается в Telegram), данные стираются |
| `/users`, `/revoke <id>`, `/allow <id>` | только администратор: список всех пользователей с цифрами, закрыть доступ (сессия завершается), вернуть |
| любой текст | бот покажет вердикт модели |

Интерактивная схема всей системы (с объяснениями «для 10-летнего»): [docs/architecture.html](docs/architecture.html), откройте файл в браузере.

## Дообучение на ваших отметках

Бот прислал предупреждение о чате, канале или группе, а это не спам: нажмите «✅ Это не спам». Бот (1) больше не трогает этот чат,
(2) запоминает текст, из-за которого сработал, и для вас такое сообщение больше не помечается, (3) если то же отметил администратор
или `FEEDBACK_MIN_USERS` разных пользователей, текст попадает в общую модель, и она переобучается в фоне без остановки бота.
Порог в 2 человека не даёт любому «научить» модель считать казино нормальным. Сохраняется только то, что вы сами отметили;
`/stop` стирает ваши сохранённые тексты. Те же кнопки работают в WhatsApp.

Обучающие данные: `python make_dataset.py` (≈6 000 примеров: русский, казахский, смесь, транслит, сложные «нормальные» сообщения
вроде «ставка по ипотеке», «фильм про казино») плюс `data/handwritten.csv` (≈150 ручных примеров, на них честно считается качество). Тесты: `python tests_feedback.py`, `python tests_access.py`.

## Аналитика

Сайт `web/` (Vercel, позже Telegram Mini App): «Мой обзор» и «Админ». Обычный пользователь видит только свои цифры.
Админ видит всех пользователей: имя, @username, id, статус, подключённые каналы, режимы, активность и цифры, и может открыть
подробные графики любого (о чём пользователей предупреждает бот при подключении). Тексты сообщений и данные собеседников на сайт не передаются.
Доступ по подписанной ссылке из `/report`. Подробное техническое задание: [docs/TZ.pdf](docs/TZ.pdf). Тесты: `python tests_analytics.py`, `node web/tests/test_api.js`.

## Проверка ссылок

Каждая ссылка (включая «голые» домены, обфускацию `1win[.]com` и адреса, спрятанные под текстом «кликни сюда») проверяется:
локальные списки доменов казино и фишинга (blocklistproject) + фид OpenPhish, маскировка под бренды (kaspi, halyk…), punycode,
IP вместо домена, подозрительные зоны, возраст домена (RDAP). Короткие ссылки раскрываются на самом сокращателе.
**На сайты по ссылкам бот не ходит** (нет SSRF), поиск по спискам занимает микросекунды, результаты кэшируются.
Чужим ссылки усиливают оценку сообщения; **знакомым** проверяются тоже (вдруг взломали), но только предупреждение при явной
опасности (`LINK_WARN_KNOWN`), без блокировки. Тесты: `python tests_links.py [--net]`.

## WhatsApp (Evolution API)

`/whatsapp` создаёт экземпляр Evolution `sg_<ваш id>`, присылает QR (Настройки → Связанные устройства), и бот проверяет
сообщения новых собеседников и группы тем же классификатором; предупреждения приходят в Telegram.
Экземпляры не копятся: «уборщик» раз в минуту удаляет неподключённые (старше `WA_PAIR_TTL_SEC`), осиротевшие и
давно потерявшие связь. Вызовы к WhatsApp идут только при состоянии `open` и с таймаутом (иначе Evolution зависает).
Evolution и его Postgres/Redis работают в `docker-compose.yml`, порты наружу не публикуются; вебхуки идут по внутренней сети.
WhatsApp строго относится к автоматизации: блокировки номера возможны, поэтому по умолчанию только уведомления.

Тесты модуля: `python tests_whatsapp.py`.

## Честные ограничения

- Данные обучения в основном синтетические (шаблоны + обфускация); оценки на ручных примерах оптимистичны.
- Картинки не анализируются. Личные чаты и группы/каналы проверяются только по тексту.
- Автоматизация личного аккаунта — серая зона правил Telegram. Файл сессии даёт полный доступ к аккаунту: не публикуйте его.
